## Проект PyTaskManager
Приложение FIBER Task Manager - это десктопное приложение для управления личными задачами и продуктивностью, разработанное на Python с использованием PySide6.  
Приложение помогает отслеживать время затраченное на выполнение задач, перерывы, продуктивность, отслеживать сроки

![](https://github.com/DmProkofiev/PyTaskManager/blob/main/Resources/FIBERTMico.png)       

Архитектурный Паттерн: MVVM, Repository, UnitOfWork  
Библиотеки: PySide, PyTest, dependency-injector  
Интерфейс: PySide6 (Qt for Python)  
Тестирование: PyTest  
DI-контейнер: dependency-injector  
База данных: SQLite  

## Модели:  
1)Task (рич)  
2)Session (рич)  
3)Note (рич)  

## Функционал:  
1) Управление задачами (CRUD): создание, чтение, редактирование, удаление задач с разными типами периодичности (разовые, ежедневные, еженедельные, ежемесячные, ежегодные)
2) Ведение заметок с привязкой к задачам
3) Таймер продуктивности с учётом времени работы и перерывов, привязка к задачам
4) Статистика по задачам на главной панели
5) Визуальное выделение приоритетов и статусов задач цветом в таблице
6) Фоновый режим работы приложения: быстрый доступ через иконку в системном лотке
